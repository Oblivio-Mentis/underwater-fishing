# RAID-011 — запуск и плейтест

Windows x64: распакуйте весь `Builds/RAID011-Playable.zip`. `Start-Solo.cmd` сразу запускает локального хоста для одного игрока; `Start-Menu.cmd` открывает выбор подключения. Не запускайте старые сборки PR #7/#8 вместе с этим хостом. Для редактора используйте `Assets/_Game/Scenes/InterfaceVerticalSlice.unity`.

Оба ярлыка сохраняют прогресс в `UserData/team-progress.json` рядом со сборкой. Непосредственный запуск EXE использует отдельный `raid011-team-progress.json` в Unity persistentDataPath. Прежний `team-progress.json` PR #7 остаётся отдельным. Сохранение принадлежит хосту; выход хоста завершает сессию. Копируйте весь каталог сборки, а не один EXE.

## Управление

- WASD и мышь — движение и обзор; Space / Ctrl — вверх / вниз, Shift — ускорение.
- ЛКМ — выстрел гарпуна, удержание — подтягивание. При рывке и высоком натяжении отпускайте ЛКМ. R освобождает добычу или трос напарника.
- Если вас тянет другой игрок, R отменяет связь и даёт 3 секунды защиты от повторного захвата. Это работает и при открытом меню.
- E при наведении на бортовой компьютер — открыть панель; Esc — закрыть панель / открыть паузу. В меню курсор свободен, игровой ввод блокируется.
- У контейнера E открывает грузовой пост и загружает переносимый улов, если хватает места. Кнопка «Запустить подъём» начинает доставку; дождитесь разгрузки и возврата контейнера.
- F удерживать возле беспомощного/застрявшего напарника — спасение. E рядом с его снастью — помощь с рыбой.

## Короткий маршрут

1. На навигационном компьютере выберите первую глубину и подтвердите переход. Все водолазы должны быть внутри.
2. Выйдите через кормовой проём сзади. Поймайте рыбу, удерживая натяжение в безопасной области.
3. Загрузите её в контейнер и запустите подъём. Рыба попадёт в общий резервуар после разгрузки.
4. На борту выберите один из двух пультов по сторонам резервуара: **вся рыба в переработчик** либо **вся рыба в пасть**. Подтверждение показывает точный состав и выход; повторный запуск занятой линии запрещён.
5. Наблюдайте поток в трубах и рыбу на лентах. Ресурсы/пища начисляются по прибытии, а не при нажатии кнопки. Техгруз перерабатывается отдельно через монитор резервуара.
6. Для установки улучшений вернитесь на базу через навигацию. Катушка облегчает ловлю, корпус открывает вторую глубину; все пять улучшений общие для экипажа. Периодически кормите чудовище: недокорм вызывает нападение и потерю улова, улучшения сохраняются.

## LAN и Steam

Локальная проверка: хост — «Создать» → «Локальная проверка» → «Хост». На другой копии/ПК — «Присоединиться» → «Локальная проверка» → IP хоста → «Подключиться». На одном ПК используйте `127.0.0.1`. Максимум 5 игроков вместе с хостом.

Steam: нужны два ПК с разными аккаунтами Steam и одинаковая сборка RAID-011. Оба запускают игру вручную. Хост выбирает Steam и создаёт лобби; ID берётся в панели экипажа, гость вводит его в разделе присоединения. При доступном Overlay работает кнопка приглашения. Прототип использует development AppID 480 и протокол `ui-011-factory`; собственная страница Steam ещё не требуется для этого теста. [Предыдущая инструкция со ссылками Valve/транспорта](../HOW_TO_PLAY.md#steam-без-страницы-игры).

Проверка через два Steam-аккаунта и нативный Windows-ввод ещё ожидает участников. Автоматические проверки выполнены через Unity MCP и фоновые Windows LAN-клиенты, без переключения пользовательских окон.

## Проверить вручную

Походить внутри/через кормовой выход, проверить обе трубы и конвейеры; пройти ловлю → доставку → покупку корпуса → глубину 2. С другом — отменить трос клавишей R, спасти водолаза, одновременно подтвердить одну покупку и отключить клиента. Отдельно проверить Alt-Tab/Overlay, скорость мыши и читаемость физического монитора в своём разрешении. Ручная оценка удобства и визуала ещё не пройдена.
