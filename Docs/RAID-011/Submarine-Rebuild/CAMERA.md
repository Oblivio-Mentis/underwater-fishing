# Камера и игровые кадры

Все кадры C и D сняты из камеры владельца водолаза в Play Mode, 1920×1080. HUD и прицел принадлежат игре. Для постановки обзора Unity MCP ставил игрока в указанную точку. Движение рыбы, падение на ленты, начисление пищи, анимация пасти и выстрел гарпуна происходили через обычные игровые команды.

| Кадр | Условия |
|---|---|
| C01 | Главный отсек. Игрок (7,5 / 1,1 / 3,5), взгляд на резервуар (0 / 2,8 / −6), FOV 80°. |
| C02–C03 | Реальный подъём по ступеням и выход к наружной площадке. |
| C04 | Идёт переработка. Камера находится на главном проходе цеха, справа от конвейеров. |
| C05, D02, D05 | Вид от левого борта на внутреннюю пасть. Игрок (−4,1 / 1,05 / 9), цель (0 / 3,4 / 15,4). Последние рыбы входят в рот, затем следует выброс. |
| C06 | Наружный вид на тело чудовища и соединение с носом. Игрок (25 / 13,5 / 32), взгляд в сторону (0 / 3,65 / 12). |
| C07–C10 | Доступ к переработчику с кормы, прицеливание ПКМ с FOV 52°, проход через цех и физический компьютер улучшений. |
| D01, D03 | Соединения резервуара. D01 снят с позиции (4,9 / 1,1 / −10,5), D03 с (8,75 / 1,12 / −1,3). |
| D04 | Вылет троса после подтверждённого выстрела в переборку. В сетевой проверке зацепления обе роли исполняли реальные FishNet-владельцы. |
| D06 | Первые рыбы выходят из резервуара в стеклянную трубу. Снято через 2,65 с после запуска кормления с физического пульта. |

Before-main-room показывает предыдущую лодку с позиции (3,35 / 1,2 / 0,5). После увеличения судна позиции съёмки главного зала изменились. В демонстрации использован изолированный запас рыбы, чтобы показать оборудование в работе. Игрок начинает новую партию с обычным игровым балансом.
