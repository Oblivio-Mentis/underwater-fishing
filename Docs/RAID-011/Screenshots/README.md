# RAID-011 — реальные кадры Play Mode

Снимки получены через `ScreenCapture` из камеры локального водолаза в работающем Editor Play Mode. Это не Scene View и не макеты. Окна пользователя не активировались. Фоновые Windows-клиенты участвовали в сетевых проверках; окончательные PNG сделаны в Editor, а не в batch-player.

Запас, таймер голода и граничные состояния подготовлены изолированными серверными fixtures. Значения затем читаются из настоящих реплицированных данных; подтверждения, покупки, маршруты, рыбалка и лебёдка используют игровые команды. F22 показывает существующего хищника, временно остановленного для осмотра модели. Оценка визуала человеком ещё ожидается.
