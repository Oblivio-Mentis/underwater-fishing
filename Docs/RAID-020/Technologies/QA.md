# RAID-020 · Практическая проверка

Проверки проводились 26 ноября 2026 года в Unity 6000.5.6f1 и в Windows Development Player с транспортом FishNet Tugboat. Сетевые участники работали в отдельных процессах на одном компьютере. Каждый запуск использовал временную кампанию, новые профили и свободный UDP-порт.

## Нагрузка

На одном хосте при 48 живых рыбах и 40 установках измерены 60 шагов полной флотилии с публикацией состояния. 95-й перцентиль времени серверного шага и подготовки снимка вместе составил 1,57 мс. Сериализованный снимок занял 45 270 байт. Второй замер изолировал промышленную симуляцию 128 смешанных установок. За 120 шагов её 95-й перцентиль составил 0,145 мс, максимум — 2,21 мс. Счётчик выделений памяти в этой сборке недоступен. Размер JSON дан до транспортной упаковки. Фактический FPS и задержки через интернет здесь не измерялись. [Исходные замеры](industry-runtime.json)

## Как повторить

1. В редакторе откройте меню **RAID → Technologies → Build Windows QA**. Исполняемый файл появится в `Builds/RAID020-Technology-QA`. Для модульных проверок откройте **Window → General → Test Runner**, выберите EditMode и Run All.
2. Из корня проекта выполните следующие команды в PowerShell. Скрипты сами создают изолированные подкаталоги, запускают хост и остальных участников и завершают свои процессы.

   ```powershell
   $player = "Builds/RAID020-Technology-QA/UnderwaterFishing.exe"
   $reports = Join-Path $env:TEMP "raid020-checks"
   python Tools/RAID020/run_technology_crew.py $player 2 $reports
   python Tools/RAID020/run_technology_crew.py $player 4 $reports
   python Tools/RAID020/run_fishery.py $player $reports
   ```

3. Для проверки через интерфейс запустите Development Player с параметрами `-raid-host -raid-local-port <свободный порт> -raid-profile <новый GUID> -raid-rack-ui <новый каталог> -raid-save <новый каталог>/rack-ui-campaign.json`. Там появятся кадры и `rack-ui-report.json`. Для промышленного прогона используйте `-raid-industrial-qa <новый каталог>` и `-raid-save <новый каталог>/industry-campaign.json`.

Проверочные программы размещают участников и предметы в заданных начальных условиях, чтобы воспроизводить опасные и редкие ситуации. Расчёты долгосрочной окупаемости приведены отдельно от игровых замеров. [Экономика](ECONOMY.md) · [Управление и состав ветки](README.md)
