# RAID-024 · Гоша: живая охота, материалы, инкрементальная прокачка

Ветка `raid/024-gosha-overhaul` от `b261a0d` (`raid/020-nereid-modular-rebuild`). В ветку влита `raid/021-023-fishing-coop-feel` Kimi (`38a1e36`): звук рыбалки, соло-буксировка, загрузка клети по ЛКМ.

## Что изменилось в игре

| Было | Стало |
| --- | --- |
| `H` резервировал ближайшую к водолазу рыбу, выключал её `FixedUpdate` и коллайдеры, Гоша «подплывал» к застывшей точке | Рыба остаётся обычным серверным `FishActor`: плывёт, видит Гошу как хищника через тот же `Sense`, что и водолаза, убегает, остаётся доступной гарпуну. Захват только при фактическом контакте челюстей с рыбой при свободной линии |
| Личные перки Гоши у каждого игрока | Один командный сектор на 31 узел, оплата из общей казны, ранги видны всем |
| Доставка только в руки | Руки → открытая клеть (Доставка III) → собственный приёмник на правом борту с трубой в аквариум (Доставка V) |
| Материалы Гоша не трогал | Катушки и ящики приборов с дна: реальные `LootActor`, один носитель, тот же `CargoId` в клети или сухом лотке |

### Управление
`G` ко мне · `H` работа (Самостоятельность I: одна рыба; V+: непрерывная смена; повторное `H` заканчивает) · `K` материалы (Нюх I+) · `J` сопровождение. Строка статуса в HUD показывает занятие, груз и счёт экспедиции.

## Архитектура сервера
`RaidWorld.GoshaOrders.cs`: `RequestGoshaOrder` → `TickOrder` → `TickWork` → `FindTarget` (`SelectFish`/`SelectLoot` с оценкой расстояния, риска, взгляда экипажа, скорости рыбы) → `HuntFishTick` (чистый `GoshaHuntBrain.Step` + `GoshaSwimRoute` обход) → `FishActor.CaptureForGosha` (атомарно на сервере) → `DeliverTick` (`Receptor` → `Cage` → `Hands`) → `TeamProgress.Deposit`/`LoadCargo`/`HarpoonTool.AcceptGoshaCatch`. Клиенты получают `GoshaSnapshot` (`Load`, `Work`, `Lunge`, `Task`, счётчики, `HatchDeliveries`+`HatchCargoId`); `GoshaView.Work.cs` рисует пузыри, рывок, ил, сумку, трал; `WetCargoShoal.FollowHatch` ведёт модель рыбы по трубе приёмника в аквариум.

## Известные ограничения
- Сценарий логистики (катушка → клеть, рыба → приёмник → аквариум) написан, но прогон в редакторе не завершён: Unity падал при выходе из Play Mode из-за доступа к уничтоженному объекту в `HarpoonTool.FishInSlot` (исправлено, повторный прогон нужен).
- Нюх III–V: органика и редкие тайники не имеют физических префабов в сцене; ранги покупаются, но добавляют только радиус и приоритеты. Добавить префабы нужно отдельно.
- Звук Гоши не добавлен: по решению №9 игра идёт без звука.
- Двухпроцессный Windows-прогон и видео не сделаны в этой сессии.
