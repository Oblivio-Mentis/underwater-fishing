# Гоша на палубе и мяч

22 ноября 2026 года два отдельных процесса Windows x64 прошли 68 проверок в сцене `InterfaceVerticalSlice`, сборка `5525c0d`, Unity 6000.5.6f1, локальное соединение FishNet. Оба игрока использовали игровые камеры 1920×1080. После перезапуска обоих процессов ещё 4 проверки подтвердили загрузку приручённого Гоши и единственного экземпляра питомца у команды. [Протокол игры](windows-pair.json) · [Протокол перезапуска](restart.json)

| Ситуация | Результат в игре |
| --- | --- |
| Другой игрок гладит питомца | Гоша поднялся на руки подключившегося игрока. Хост видел питомца у него на руках. Повторное E вернуло Гошу на палубу. [Камера владельца](cradle-owner.webp) · [Камера напарника](cradle-observer.webp) |
| Владелец держит мяч | При повороте камеры на 46° мяч остался в той же точке относительно перчаток. Удержание ЛКМ перевело руку в замах. Открытие меню отменило замах, сохранив мяч. [Мяч и активная ячейка](ball-in-hand.webp) · [Замах](ball-windup.webp) |
| Бросок на пол | Гоша пробежал к мячу, поднял его перед двумя белыми жвалами и принёс бросившему. [Возврат с мячом](ball-in-mandibles.webp) |
| Мяч возле острого края боковины левой лестницы | Гоша добрался до исходной точки у обоих лестничных маршей и вернул мяч. Сервер в обоих случаях подтвердил отсутствие аварийной перестановки. [Мяч у боковины](forward-stair-ball.webp) · [Передний марш](forward-stair-fetch.webp) · [Задний марш](aft-stair-fetch.webp) |
| Мяч на верхней смотровой площадке | Гоша поднялся по лестнице, подобрал мяч на высоте 3 м, спустился и вернул его игроку внизу. [На площадке](gallery-fetch.webp) |
| Бросок в пасть | После пересечения губ тот же физический мяч вылетел обратно на палубу. Гоша вернул его бросившему. [Мяч перед пастью](mouth-return.webp) |
| Мяч в закрытом объёме резервуара | Игра перенесла застрявшую физическую сферу в доступный проход, откуда Гоша её принёс. Сценарий сверил экземпляр физического объекта и его количество после всех возвратов. |
| Бросок в другого игрока | Напарник получил мяч при прямом столкновении. Гоша догнал его, забрал мяч и отпустил на палубе. Здоровье, кислород и идентификатор рыбы в заранее заполненном кармане сохранились. |

Для повторяемой проверки боковин и галереи сценарий задаёт исходную точку свободного мяча и даёт ему упасть под действием игровой физики. Для пасти он задаёт направление и начальную скорость физической сферы. Преследование, подъём, захват и возврат выполняет игровая логика. Отдельные броски на пол и в напарника проходят через удержание и отпускание ЛКМ. Случай с непроходимым резервуаром намеренно начинает с мяча внутри оборудования.

Для воспроизведения на Development-сборке у хоста задаются отдельные каталоги и новый путь сохранения через `-raid-host -raid-local-port 17868 -raid-gosha-trial <host-dir> -raid-gosha-peer <peer-dir> -raid-ui-probe <host-dir> -raid-save <team.json>`. Второй процесс запускается с `-raid-client -raid-local-port 17868 -raid-ui-probe <peer-dir>`. Результат появляется в `<host-dir>/gosha-crew.json`. Для проверки загрузки оба процесса запускаются заново с сохранённой командой и новыми каталогами журналов.
