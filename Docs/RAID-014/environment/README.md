# Вода и ламинария — игровой прогон C

Два отдельных процесса Windows Development x64 загрузили `InterfaceVerticalSlice` на одном компьютере. Хост работал с D3D11, второй клиент — через локальный FishNet/Tugboat без графики. Кадры сняты камерой водолаза хоста. Исходники прогона находились в ветке окружения на базе RAID-013. Основной прогон выполнен на `17091b0`.

Для сопоставимых кадров сценарий ставит водолазов на заданные позиции и выключает директора угроз. Переход через рощу воспроизводится контролируемым движением водолаза второго клиента. Ламинария отклоняется от его реплицированного тела. Проход записан внешней камерой другого игрока от первого лица. Положение лабораторной камеры и состояние игрового мира записаны в JSON.

## Производительность

Одна камера на мелководье, RTX 4070, Windows, D3D11, режим PC, URP PC_RPAsset, 1280×720, масштаб 1, MSAA 1, VSync 0, без лимита FPS. Сценарий последовательно выключает, включает, оставляет включёнными и выключает только два новых эффекта. Перед каждым четырёхсекундным интервалом выполняется секундный прогрев. Каждое измерение включает полноценный URP RenderRequest камеры и синхронное чтение пикселя, чтобы скрытое окно не засчитывало пропущенные кадры. Экранный HUD не входит в этот замер. Среднее вычислено как число завершённых кадров, делённое на суммарное время интервалов.

| Прогон | Выкл., FPS | Вкл., FPS | Вкл., FPS | Выкл., FPS | В среднем выкл. / вкл. |
| --- | ---: | ---: | ---: | ---: | ---: |
| [Первый](water-trial-first-profile.json) | 235,5 | 255,7 | 258,6 | 268,1 | 251,8 / 257,1 |
| [Повтор](water-trial.json) | 268,9 | 256,9 | 231,8 | 204,4 | 236,6 / 244,3 |

Разброс контрольных интервалов превышает разницу между средними. В этих условиях измеримого снижения средней частоты при включении обоих эффектов не обнаружено. Это замер одной камеры при фоновой работе на машине; он не устанавливает стоимость эффектов на других GPU и минимальный FPS в остальной игре.

Для повтора запустить оконный Development-хост с `-raid-host -raid-water-trial <папка> -raid-save <отдельное-тестовое-сохранение> -screen-fullscreen 0 -screen-width 1280 -screen-height 720 -force-d3d11 -raid-local-port 7784` и второй экземпляр с `-batchmode -nographics -raid-client -raid-local-port 7784`. Для кадра глубины 2 требуется уже открытый второй район. Сценарий завершается записью `environment.json`.
