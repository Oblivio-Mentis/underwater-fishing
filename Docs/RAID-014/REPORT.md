**Windows x64 Release.** Архив `Builds/UnderwaterFishing-RAID014-Playable.zip` содержит 215 файлов, 49 633 942 байта. После распаковки `Start-Menu.cmd` открывает меню, `Start-Solo.cmd` запускает одиночную игру. Unity BuildReport — 0 ошибок и 0 предупреждений. Два D3D11-процесса Release вошли в одну сессию FishNet/Tugboat и оставались подключёнными пять секунд наблюдения. [Хеш SHA-256 и проверка архива](validation/windows-release.json) · [Протокол соединения Release](validation/windows-release-smoke.json).

**Условия проверок.** Игровые сценарии выполнялись на одном Windows-ПК. Автоматизация использует отдельные сохранения и ставит участников в контрольные позиции. Выстрелы подтверждает сервер, движение и перекрытие дверей рассчитывает физика игры. Рыболовный сценарий приостанавливает ИИ рифовых хищников при проверке уникальности улова. Для проверки предельного времени кислорода сценарий задерживает насос. Проверка обороны и спасения объединяла редактор в Play Mode и отдельный Windows-клиент. Для рыбалки, Гоши и окружения запускались отдельные экземпляры Windows Player. Интернет-сессию через два Steam-аккаунта на разных ПК не проводили. Совместимая версия нового сетевого состояния экипажа объявляется в лобби как `nereid-submarine-expedition-v3`.
