# RAID‑019 · Единая радиальная прокачка

Ветка ответвлена от `raid/015-personal-skill-tree` на `6f8cda2`. В первую поставку на этой ветке вошла геометрия RAID‑015. [Состав объединённой сборки NEREID Expedition](INTEGRATION.md).

## Данные

- `RadialProgressionCatalog.asset` задаёт сектора, названия, цены и эффекты. Узел является отдельным рангом. Стабильные ключи наподобие `harpoon.cable.03` однозначно соответствуют сетевому ID `номер_линии × 16 + ранг`.
- В восьми направлениях по пять числовых линий и одному уникальному модулю. Общий каталог содержит 248 узлов. Граф зависимостей, величина эффекта и цена доступны интерфейсу и серверу из одной модели.
- Эффект линии берётся из старшего приобретённого ранга. Например, трос III даёт 36% суммарного бонуса. [Все формулы и условия](CATALOG.md)

## Покупка

1. Клиент отправляет ID узла и две известные ревизии. FishNet связывает запрос с дивером отправителя.
2. Хост проверяет луч прицела, дальность монитора, состояние игрока и экспедиции, принадлежность профиля, условия ранга и четыре ресурса.
3. Казна и списки рангов обновляются в одной транзакции. При отказе записи восстанавливаются баланс, ранги, ревизии и затронутые таймеры.
4. Хост отправляет подтверждение и публичный снимок. Каждый клиент отдельно получает свои личные ранги. Приватные ключи остаются на хосте.

## Игровые системы

Два гарпуна разных водолазов по-прежнему нужны для крупной рыбы. Ускоренный шлюз отрабатывает все фазы и проверяет проём дверей. Клеть резервирует места в аквариуме перед подъёмом. Общий Гоша исполняет личные приказы по очереди. Результат переработки учитывает отдельный дробный остаток каждой валюты.

## Монитор

Физический `SkillTreeStation` установлен в машинном отсеке объединённой подлодки. Камера игрового мира сохраняет свой угол обзора. При переключении приближается полотно интерфейса. В подробном режиме переиспользуются 31 кнопка и одна графика связей. Материалы казны и параметры перка видны отдельно от графа. Знаки сгенерированы как восемь белых гравированных приборных пиктограмм на прозрачной подложке. Для Гоши выбран силуэт рачка с усиками. ## Сохранение

Формат новой кампании — схема 4. Он сохраняет текущую доступную глубину, казну, профиль каждого игрока, общие ранги и состояние Гоши. Недоступное или несовместимое сохранение блокирует запись в этот файл с объяснением в игре. Архив включает запуск отдельной кампании. [Управление и запуск](SKILLS.md)
