# RAID‑019 · Монитор прокачки

Подойдите к правому борту главной палубы и нажмите ЛКМ по экрану NEREID. Выберите один из восьми секторов. Персональные узлы отмечены голубым, командные — янтарным и отдельным знаком.

| Клавиша | Действие |
|---|---|
| ЛКМ | Открыть сектор или посмотреть перк |
| ПКМ по узлу | Купить выбранный ранг |
| Колесо | Приблизить полотно к прицелу |
| Удержание ЛКМ на пустом поле | Сдвинуть дерево |
| Esc | Из ветки к кругу, из круга к игре |
| V | Экспедиционный сканер после открытия |
| B | Гидрорывок после открытия |
| G / H / J | Позвать Гошу, попросить мелкую рыбу, включить сопровождение |

Все узлы используют одну казну экипажа. Корпус I открывает вторую глубину на навигационном мониторе. До первой покупки хитин можно получить из Needlefish и Lanternfish на первой глубине.

`Start-Solo.cmd` запускает кампанию из `UserData/raid019-team-progress.json`. `Start-New-Campaign.cmd` запускает отдельную чистую кампанию. Для возобновления дополнительной кампании используйте `-raid-save` с путём к нужному файлу.
