# RAID‑016 · Визуальное обновление NEREID

Основа — RAID‑014 `13a3acb`. Рабочая сцена — `InterfaceVerticalSlice`.

- Первый горизонт получил коралловые сады, песчаные отмели и обломки промерного катера. На втором есть отдельный рельеф и собственные коллизии, базальтовые иглы и несколько слабых светящихся выходов в разломе.
- Камни Kenney, декоративные рыбы и девять модулей Quaternius встроены в рабочую сцену. Модули оформляют резервуар, цех, задние панели мониторов и шлюз. Существующие каркасы, ограждения и коллизии станций участвуют в игре.
- У казны, выхода переработки и цен улучшений общие пиктограммы биомассы, хитина, металлолома и электроники. Подтверждённое пополнение подсвечивает прибавку к балансу. Мяч использует собственную пиктограмму в первом свободном номерном кармане. Отдельные названия и символы различают резервуар, мастерскую и навигацию.
- Ловимый парусный скат получил обновлённый материал. Фоновые стаи имеют свои модели и анимацию плавников. Пузырьки и взвесь используют уже работающие источники NEREID.

Снято 17 пар в 1280×720 из камеры владельца. Координаты и цели заданы общими отметками. Крупный скат выставлен в сцене, попадание по нему выполнено штатным гарпуном. Максимальный сдвиг камеры составил 1,5 см, максимальное отклонение направления — 1,70° на мониторе мастерской. На трёх точках замера ракурсы совпали. [Камеры](camera-comparison.json)

## Замеры D3D11

RTX 4070, URP PC, 1280×720, render scale 1, MSAA 1, VSync 0. Обе сборки профилировались с отключёнными Graphics Jobs. CPU — время подачи рендера камеры на главном потоке. GPU — интервал аппаратных меток D3D11. Метрики относятся к рендеру камеры, включая её стек URP.

## Воспроизведение

Для съёмки соберите Windows Development командой `Raid.Editor.Raid014Validation.Build` с аргументами `-raid-flavor qa -raid-exe <exe>`. Запустите `Tools/RAID016/Run-ArtPass.ps1 -Player <exe> -Output <новая-папка> -Peer`. Для профилирования сначала запустите `Tools/RAID016/Build-FrameTiming.ps1`, добавьте к сборке `-raid-frame-timing on` и передайте в раннер `-Timing -MarksFile <json-с-точками-замера>`. Для режима замера достаточно отметок с `benchmark: true` из `camera-marks.json`.
