# Underwater Fishing — запуск прототипа

Windows x64: `Builds/FirstPlayable/UnderwaterFishing.exe` после финальной сборки. Сцена в редакторе: `Assets/_Game/Scenes/FirstPlayable.unity`.

## Локальный кооператив

1. Запустите игру. На первом экземпляре нажмите **«Локальный хост»**.
2. На втором экземпляре оставьте IP `127.0.0.1`, нажмите **«Локальный клиент»**. Для другой машины в LAN укажите IP хоста.
3. Хост — один из игроков. Максимум пять участников; одиночный запуск разрешён для отладки.

Командная строка, из каталога сборки:

```powershell
.\UnderwaterFishing.exe -raid-host
.\UnderwaterFishing.exe -raid-client
```

## Steam без страницы игры

Прототип использует тестовый **AppID 480 (Spacewar)**. Это позволяет проверять интеграцию до регистрации собственной игры, но не создаёт страницу или собственный AppID. [Документация Valve](https://partner.steamgames.com/doc/sdk/api/example).

1. Нужны **два компьютера и два отдельных Steam-аккаунта**. Оба участника входят в Steam. Несколько Steam-клиентов на одном ПК не являются поддерживаемым тестом FishySteamworks. [Официальная инструкция транспорта](https://github.com/FirstGearGames/FishySteamworks).
2. Передайте второму участнику **весь каталог сборки** или архив, а не один `.exe`. Рядом с `.exe` должен лежать `steam_appid.txt` с числом `480`.
3. Оба вручную запускают **эту сборку RAID**. Хост создаёт Steam-лобби для друзей.
4. Хост нажимает `Esc` и передаёт **Steam Lobby ID** из панели сессии. Гость вводит ID и нажимает **«Войти в Steam-лобби»**.
5. При включённом Steam Overlay можно пригласить друга через кнопку приглашения. В режиме 480 не полагайтесь на холодный запуск из приглашения: оба сначала запускают сборку. Если Overlay недоступен, используйте ID.
6. Проверьте двух водолазов, совместную ловлю/помощь и одинаковое содержимое резервуара. Выход хоста завершает сессию; миграции нет.

Лобби проверяет идентификатор проекта и протокол сборки; Steam-транспорт допускает участников текущего лобби. Это режим разработки с общим тестовым AppID. Для публикации потребуется собственное приложение Steamworks и его AppID.

## Управление и цикл

- **WASD**, мышь — движение и обзор; **Space / Ctrl** — вверх/вниз; **Shift** — ускорение.
- **Esc** освобождает курсор; **ПКМ** возвращает обзор.
- **ЛКМ** стреляет гарпуном. Удерживайте для подтягивания, отпускайте при опасном натяжении и рывках. **R** отпускает добычу.
- **E** рядом с напарником помогает стабилизировать снасть; возле резервуара открывает терминал; у контейнера загружает переносимый улов; при наведении на ящик подбирает его.
- **F удерживать** около беспомощного или застрявшего напарника — спасение.

1. Подойдите к центральному резервуару, нажмите **E**, выберите **Depth 1**. Все участники должны находиться внутри.
2. Пройдите через передний шлюз. Ловите рыбу снаружи. Захваченная рыба остаётся грузом; материалами она станет позднее.
3. Доставьте улов к оранжевому контейнеру справа от шлюза. Нажмите **E**, затем **Esc** и **Start hoist**. Во время подъёма загрузка закрыта; можно продолжать ловить.
4. Дождитесь возврата контейнера. Команда возвращается внутрь и через терминал выбирает **Return to base**. Незавершённый грузовой цикл блокирует переход.
5. В резервуаре выбирайте **Process** для материалов или **Feed** для кормления. Один экземпляр расходуется один раз.
6. Между погружениями покупайте Reel, Fins, Tank, Hull и Winch. **Hull** требует накопительной добычи и открывает **Depth 2**. На второй глубине есть хитин, электроника и более сильная угроза.
   Первое усиление катушки и Hull доступны за биоматериал; следующие уровни используют хитин, лом и электронику. Начальной лебёдке нужен лом из ящиков Depth 1.
7. Следите за кислородом, глубиной и стрессом давления. Внутри лодки кислород восстанавливается. Голод запускает налёт на запас; технологии и улучшения сохраняются.

Все численные параметры редактируются в `Assets/_Game/Data/`. Сохранение команды хранится у хоста в `Application.persistentDataPath/team-progress.json`; клиентское сохранение не заменяет состояние хоста. При повреждении файла игра сообщает ошибку и сохраняет оригинал.

## Проверка вдвоём

Проверьте своё управление и видимость напарника; помощь на крупной рыбе; запрет загрузки при движении контейнера; выбор переработки/кормления; эффект улучшения; выход хоста. Фактически пройденные автоматические проверки и ещё не выполненные пункты перечислены в `TEST_RESULTS.md`.
