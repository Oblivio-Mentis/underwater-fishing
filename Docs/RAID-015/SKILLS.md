# Узлы монитора NEREID

От центрального узла расходятся девять лучей. В каждом порядок покупки такой. Первый узел → одна или обе развилки → четвёртый узел. Между лучами зависимостей нет. Итоговая вместимость нового контейнера с K1–K4 равна 26, с K1 — 12, с K1 и K2 — 16. P1–P4 дают +35% к каждому материалу, который уже есть в добыче. Сотые доли сохраняются вместе с казной. N1–N4 дают +45% к положительной пищевой ценности. При базовой ценности 2 результат равен 2,90. У каждого улова есть только один результат маршрута.
