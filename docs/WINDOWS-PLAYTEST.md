# Underwater Fishing — Windows playtest

Распакуйте ZIP целиком в отдельную папку. Рядом с `UnderwaterFishing.exe` должны остаться `UnityPlayer.dll`, остальные runtime DLL, `UnderwaterFishing_Data`, `MonoBleedingEdge` и `D3D12`. Не переносите один EXE отдельно. Версия, commit, состояние исходников и SHA-256 игрового кода записаны в `package-manifest.json`; контрольная сумма ZIP находится в соседнем файле `.zip.sha256`.

Запустите Steam и войдите в свой аккаунт. В папке игры:

```powershell
.\UnderwaterFishing.exe --steam-app-id 480
```

Это development-прототип с тестовым App ID 480. Для обычной игры нужны 2–5 участников; host создаёт Steam-лобби, второй игрок входит через поиск или по Steam Lobby ID. Оба используют один архив. Подробный порядок и ограничения приглашений: [STEAM-TEST.md](STEAM-TEST.md).

## Управление

| Клавиша | Действие |
| --- | --- |
| WASD, мышь | Плавание и обзор |
| Space / левый Ctrl | Вверх / вниз |
| левый Shift | Ускорение, повышенный расход кислорода |
| ЛКМ | Выстрел гарпуном |
| удерживать ПКМ | Подтягивать рыбу катушкой; отпускайте на сильных рывках |
| E | Взять добычу, загрузить/поднять контейнер, открыть терминал |
| R | Отпустить рыбу или предмет |
| удерживать F рядом с напарником | Помогать при ловле/переноске; дать аварийный кислород потерявшему сознание |
| удерживать E у завала | Освободить придавленного напарника |
| Q | Потратить изготовленный заряд сонара в экспедиции |
| Tab | Информация об экспедиции и согласие на возвращение |
| Esc | Закрыть терминал / открыть меню |

Держите нужный объект в прицеле и подходите достаточно близко. Подсказка на экране уточняет доступное действие. Внутри подлодки кислород восстанавливается. Следите за O₂, глубиной, нагрузкой и состоянием давления в HUD.

## Маршрут полного цикла

1. Соберитесь вдвоём в подлодке. У носовой стены находятся терминалы **«Экспедиция» → «Переработка» → «Мастерская» → «Подношение»**. Подойдите к «Экспедиции», наведитесь на экран и нажмите E. После подготовки начнётся первый день.
2. Идите к середине каюты, затем вправо по стрелке **«Шлюз»**. Сначала выйдите из корпуса, потом погружайтесь. Под подлодкой расположен жёлтый грузовой контейнер; металлолом есть недалеко от выхода на глубине около 12 м, электроника — глубже у обломков. Один игрок может собирать технический груз, второй — ловить рыбу.
3. Попадите гарпуном в рыбу, удерживайте ПКМ с паузами на рывках. Напарник подходит, смотрит на водолаза с тросом и удерживает F. Когда рыба истощена, подтяните её близко и нажмите E. Крупную рыбу удобнее переносить вместе с помощником.
4. С добычей подойдите к контейнеру и нажмите E, чтобы загрузить её. Со свободными руками E запускает подъём. Дождитесь разгрузки в защищённый отсек; контейнер вернётся вниз для следующей партии. Для первого улучшения и сонара соберите рыбу, металлолом и электронику: цены показаны в мастерской, стартового запаса материалов нет.
5. Возвращайтесь через тот же шлюз: из-под днища сначала обойдите правый борт, затем поднимитесь к проёму и войдите в каюту. Не пытайтесь всплыть сквозь палубу. У «Экспедиции» нажмите E для возврата. Активные участники должны быть на борту либо подтвердить согласие через Tab.
6. На базе у «Переработки» выберите конкретные доставленные предметы. Купите кислородное улучшение и изготовьте заряд сонара у «Мастерской». Во втором выходе проверьте увеличенный кислород и нажмите Q рядом с рыбой/лутом: появятся временные отметки контактов.
7. Во втором выходе доставьте рыбу для квоты. На базе у «Подношения» отметьте её **«В резерв»**, ориентируясь на суммарную ценность и требование. Зарезервированная рыба не перерабатывается; резерв можно снять. Для третьего дня можно выйти и вернуться раньше таймера.
8. После третьего возвращения откроется окно подношения. У терминала можно выбрать и рыбу последнего дня. Наберите квоту и нажмите **«Передать»** до истечения отсчёта. Успех сохраняет ресурсы и улучшения и повышает следующую квоту; нехватка еды завершает забег. После поражения начните новый забег доступной в интерфейсе кнопкой сброса.

Нормальный выход длится около семи минут и может быть завершён раньше. При потере сознания нужен напарник с аварийным кислородом; после смерти игрок наблюдает до возвращения экипажа. Самостоятельно продолжить экспедицию через экран смерти нельзя.

Для отчёта сохраните версию/хеш из manifest и укажите день, действие и фактический результат. Локальные тесты не подтверждают игру разных Steam-аккаунтов: внешняя проверка выполняется отдельно по [Steam-чеклисту](STEAM-TEST.md).
