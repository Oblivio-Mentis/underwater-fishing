# RAID-003 — гарпунная охота

Реализован играбельный полигон охоты поверх foundation из PR #1. Полный Core Loop остаётся целью следующих этапов.

## Реализовано

- Два вида рыб с настоящим серверным UniversalFSM: патрулирование, тревога, бегство, захват, рывки, усталость, поимка и побег.
- Серверный выстрел гарпуном, проверка попадания/дальности, единственный владелец рыбы.
- Пространственный трос: натяжение, катушка, ограничение длины, обрыв с запасом времени, отпускание.
- Силы воздействуют на рыбу и водолаза; внешний рывок проходит в существующую модель давления.
- Утомлённую рыбу можно взять в руки, переносить и отпустить; большая добыча замедляет плавание.
- Помощь напарнику по F: проверка расстояния/направления/видимости, ограниченное усиление без бесконечного суммирования.
- Клиентские SFX и вспышки через UniversalFSMPresentation, видимый трос, гарпун, HUD.
- FishingGym с автоматическим локальным хостом и настройками катушки/троса по Tab.

## Основные файлы и архитектура

`Fishing/Creatures` и `Fishing/Tether` — независимые от сети расчёты и данные.
`Fishing/Network` — серверная интеграция, команды владельца и подтверждённые снимки.
`Fishing/Presentation` — отображение и звуки; `Data/*Fish.asset`, `TetherBalance.asset` — баланс.
`Editor/FishingBuilder.cs` создаёт воспроизводимые prefab/сцены; `Fishing/Debug` — добровольно включаемые акторы проверок.

## Запуск

В Unity открыть `Assets/_Game/Scenes/FishingGym.unity` и Play; Tab открывает настройку полигона.
Обычная сессия: `UnderwaterFishing.unity`, Steam-лобби или LAN-кнопки.
WASD, Space/Ctrl, мышь; ЛКМ выстрел, ПКМ катушка, R отпустить, E взять утомлённую рыбу, F помогать напарнику.

Проверки из корня: `powershell -NoProfile -ExecutionPolicy Bypass -File tools/Run-LogicTests.ps1`,
`powershell -NoProfile -ExecutionPolicy Bypass -File tools/Verify-Network.ps1 -Players 5`,
`powershell -NoProfile -ExecutionPolicy Bypass -File tools/Verify-Fishing.ps1 -WaitForShutdown`.
Для кадров настоящего графического клиента добавить `-Capture` к последней команде.
Сборка при закрытом Editor: `powershell -NoProfile -ExecutionPolicy Bypass -File tools/Build-Windows.ps1`.

## Ограничения и риски

Полный сетевой захват крупной рыбы ещё не проверен; её рывки/нырки проверены модельными тестами.
Пользовательский плейтест ощущений ещё не проведён. Steam между разными аккаунтами остаётся непроверенным.
Завал/спасение, контейнер/лебёдка, экспедиции/дни, ресурсы/улучшения и подношения — следующие этапы.
Переноска пока кинематическая; сложная физика груза не реализована.
