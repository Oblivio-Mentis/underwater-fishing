# RAID-006 — экспедиции и игровые дни

Git: код `1def145`; [draft PR #5](https://github.com/Oblivio-Mentis/underwater-fishing/pull/5), база `raid/005-cargo`. main не объединялся.

## Реализовано

- Серверные Base → Preparing → Expedition → Return → Debrief → Base, три дня до Offering; предусмотрены Success и Failure.
- Нормальный минимум2 игрока; отдельный Development Mode допускает одного. Продолжительность420с, быстрый режим45с, отладочная длительность задаётся аргументом.
- Терминал реально запускает вылазку и запрашивает возвращение; диапазон, видимость и фаза проверяются сервером.
- Вернуться досрочно можно, когда живые участники на борту или дали согласие через Tab. Отключённые/погибшие не блокируют модель согласования.
- Нормальное возвращение запускает текущий груз и ждёт разгрузки; таймер и ограниченный watchdog обеспечивают аварийное завершение.
- Реальные циклы появления и удаления рыбы/лута/завала; защищённый отсек сохраняется, незакреплённая добыча теряется.
- Пещера базы и зона остова переключаются синхронно. Перенос экипажа заново инициализирует витальные показатели.
- Шлюз закрыт на базе и открыт в вылазке; вода ограничена коллайдерами. Отдельные debug gyms сохраняют самостоятельную проверку механик.
- Экран информации и согласия по Tab, корректное освобождение курсора по Esc; сброс проигранного забега доступен владельцу независимо от сознания водолаза.

## Файлы и архитектура

`Expedition/Model` — часы, дни и согласие без сети; `Expedition/Network` — факты экипажа, owner RPC, терминал и snapshots.
`World/ExpeditionWorldLifecycle` связывает существующие миры рыбы, груза и завала. `ExpeditionEnvironment` переключает геометрию/свет и шлюз.
Builder и сцены воспроизводимы; runtime копии параметров снаряжения подготовлены для следующего этапа.

## Проверки

- **88/88 Unity EditMode**, включая15 проверок фаз, минимума экипажа, согласия, мёртвых/отключённых, watchdog, дней и срока подношения.
- Windows Development0.0.1-raid006 собран.
- Два Windows-процесса: капитан доплыл до терминала и начал вылазку; клиент вышел в воду; запрос возвращения ожидал его согласия; после подтверждения оба увидели Base, день2, completed1, emergencyFalse.
- Отдельный таймаут: без голосования45с закончились, сервер выполнил аварийный Return/Debrief/Base; оба увидели ровно один завершённый день, исключений нет.
- После шлюза/границ финальный сценарий согласия повторно прошёл. Кадры клиента осмотрены в `.studioigor/captures/expedition-consent`.

## Запуск

`powershell -NoProfile -ExecutionPolicy Bypass -File tools/Build-Windows.ps1` при закрытом Editor.
`powershell -NoProfile -ExecutionPolicy Bypass -File tools/Verify-Expedition.ps1 -Capture`.
Для таймера добавить `-Timeout`. Эти проверки используют LAN.
В обычной Steam-сессии подойти к экспедиционному терминалу и нажать E. Tab открывает сведения и согласие на возвращение.
Опции Development-сборки: `--raid-fast-expeditions`, `--raid-expedition-seconds 180`, `--raid-development-mode`; отдельный `--raid-gym` предназначен только для полигонов.

## Ограничения и следующий этап
