# RAID-001 — Foundation, 17.11.2026

## Реализовано

- Unity 6000.5.7f1 / URP: пещера, доступный интерьер подлодки, шлюз-проход, ориентиры и грейбокс затонувшего объекта.
- Listen server FishNet, до пяти участников, уникальные персонажи, свободные точки появления, очистка при отключении.
- Steam: создание, поиск совместимых лобби, подключение, приглашение через overlay, обработка запуска с `+connect_lobby`.
- FishySteamworks для Steam P2P; Tugboat для локальных проверок. Серверная игровая логика не зависит от транспорта.
- Плавание с инерцией, столкновениями, вертикальным ограничением, Input Actions и локальной камерой.
- Основа RAID-002: серверные кислород, глубина, давление, нагрузка, обездвиживание/смерть и HUD.
- Первая Windows x64 Development-сборка.

## Архитектура

Клиент передаёт ограниченные команды движения через owner-only ServerRpc. Сервер рассчитывает мотор и жизненные показатели,
публикует снимки; клиенты отображают подтверждённое состояние. Формулы погружения выделены в независимую сборку.
RoutingTransport сохраняет подписки FishNet при переключении транспорта в отключённом состоянии.
Баланс — ScriptableObject. App ID задаётся через `--steam-app-id` / `SteamAppId`; 480 разрешён только в разработке.

## Ограничения и оставшийся объём

Это foundation; полный Core Loop ещё не реализован. Терминалы пока представлены геометрией и подписями.
Охота, помощь/спасение, груз, экспедиции, ресурсы, гаджет и подношения — следующие RAID-003…008.
RAID-002 ещё требует интеграции спасения и полноценного наблюдения после гибели.
Steam-соединение между разными аккаунтами/компьютерами и приглашение другого пользователя ещё не проверены.
Для релиза нужен настоящий Steam App ID. Пользовательский плейтест управления ещё не проведён.

## Запуск

1. Открыть проект Unity 6000.5.7f1 и сцену `Assets/_Game/Scenes/UnderwaterFishing.unity`, нажать Play.
2. При запущенном Steam: «Создать Steam-лобби»; другой аккаунт — «Найти Steam-лобби» или приглашение друга.
3. Для нескольких локальных процессов использовать кнопки LAN или параметры Windows-билда
   `--raid-host` / `--raid-join 127.0.0.1`.
4. WASD, Space/Ctrl, Shift, мышь; Esc открывает меню. В подлодке кислород восстанавливается.
5. Автопроверка: `powershell -NoProfile -ExecutionPolicy Bypass -File tools/Verify-Network.ps1 -Players 5`.
6. Повторная сборка: меню `Underwater Fishing > Build Windows Development`.
