# RAID-007/008 — материалы, снаряжение и подношения

## Реализовано

- Защищённый улов распределяется по уникальным ID: переработка даёт биоматериал, редкую органику, металлолом и электронику; зарезервированную рыбу нельзя одновременно переработать.
- Общие улучшения баллонов, катушек, костюмов и лебёдки покупаются между экспедициями. Сервер проверяет фазу, расстояние, стоимость, ожидаемый уровень и ревизию; повторная команда не списывает материалы повторно.
- Снаряжение применяется к runtime-копиям параметров каждого водолаза, включая позднее подключение. Следующее погружение получает приобретённые характеристики.
- Личный расходуемый сонар изготавливается за материалы; Q расходует заряд и показывает подтверждённые сервером контакты в радиусе 30 м на восемь секунд.
- После третьего дня открывается окно распределения добычи. Подношение потребляет резерв, показывает Success и начинает цикл с большей квотой; запас и улучшения сохраняются. Недостаток пищи приводит к Failure и доступному хосту новому забегу.
- Терминалы переработки, мастерской и подношения показывают реальные общие данные и причины отказа. Esc закрывает панель и возвращает управление.

## Файлы и архитектура

`Assets/_Game/Progression/Model` содержит экономику и правила без FishNet. `Progression/Network` проверяет owner RPC, публикует состояние и личные заряды. `Progression/UI` отображает терминалы и контакты; `World/ProgressionEquipment` применяет экипировку. `ExpeditionWorldLifecycle` связывает возврат, новый цикл и сброс мира. Конфигурации находятся в `Assets/_Game/Data`.

## Фактические проверки

- 111/111 Unity EditMode: экономика, расходы, отказы, взаимоисключение переработки/подношения, эффекты снаряжения, рост квоты и сброс.
- Два настоящих Windows-процесса прошли три экспедиции и три разбора. Улов и предметы реально подняты лебёдкой; ID 1, 4, 5 переработаны.
- Куплен кислородный уровень 1; следующая экспедиция дала **225 вместо 180**. Сонар изготовлен и использован: восемь контактов, заряд 1 → 0.
- Подношение 12/12 привело к Success и Base с квотой 17. Сохранились кислородное улучшение и материалы bio 3 / rare 2 / scrap 3 / electronics 2.
- Отдельный трёхдневный прогон подтвердил Failure → новый забег с исходной квотой 12. Непустой сброс проверен модельно; сетевой failure-прогон имел пустой запас.

Исходные результаты: `.studioigor/test-results/core-success/20261117-220632-329` и `core-failure/20261117-221220-638`. Владельцы передавали игровые команды, состояние через Inspector не подменялось. Это LAN-проверки; Steam разных аккаунтов ими не подтверждается.

## Запуск и ограничения

Обычная игра: [Windows-плейтест](WINDOWS-PLAYTEST.md), сеть: [Steam на двух устройствах](STEAM-TEST.md). Автоматическое воспроизведение: `powershell -NoProfile -ExecutionPolicy Bypass -File tools/Verify-CoreLoop.ps1 -Capture`; для поражения добавить `-Failure`.

Reel/Suit/Winch реализованы, их коэффициенты проверены модельно; покупка с измерением фактических параметров в сетевой вылазке отдельно не проводилась. Нет межсессионных сохранений: состояние живёт у хоста текущего забега. Человек ещё не оценивал удобство и интерес игры. Звук исключён по просьбе пользователя.

Код находится в `raid/007-progression`, [draft PR #6](https://github.com/Oblivio-Mentis/underwater-fishing/pull/6), база — `raid/006-expeditions`; main требует ревью. Итоговые проверки и ограничения: [RAID-009](RAID-009-ACCEPTANCE.md).
