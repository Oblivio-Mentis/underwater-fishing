# Collaboration infrastructure

For Kimi delegation use `lead.py` and `kimi-worker.md`, the shared external venv, and
the task-scoped gateway. Read README.md before changing or using this infrastructure.
Codex reviews actual files and evidence before accepting changes; automated scope
checks alone do not accept work. Kimi never merges or pushes. Preserve dirty user files.
Keep task logs, policies, briefs, credentials and generated worktrees out of Git.
The live Unity Editor and Blender are owned by Codex; Kimi receives Unity read access.
Do not share one Editor or Library cache between worker and integration worktrees.
